# MochaTrade

Institutional-grade, high-resilience derivatives & perpetual contracts trading terminal built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Features

- **Visible Margin Risk & Health Engine**: Continuous sub-10ms margin buffer calculations, real-time liquidation thresholds, and adverse scenario testing.
- **Transaction Recovery & Idempotency**: Resilient order state tracking, lost ACK recovery panel, rapid venue reconciliation (<100ms), and idempotent payment webhook handling.
- **Mocha Market Night ("Crew Pass")**: Squad formation, collaborative trading challenges, multi-phase scenario simulation, and growth metrics tracking.
- **Interactive Judge Demo**: Scripted 6-step demo controller to demonstrate edge-case resilience under adverse conditions.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
